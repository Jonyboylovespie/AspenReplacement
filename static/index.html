    Aspen cookie values

    Sign into Aspen, then open your browser’s developer tools. Under Application → Cookies (Chrome) or Storage → Cookies (Firefox), select aspen.darienps.org and copy the values below.

    Open Aspen’s desktop portal to find this cookie. It enables attendance, recent activity, and desktop averages.

    Copy only each cookie’s value. Your session is encrypted on the server. When it expires, enter fresh values here.
